## 1. Опис проекту

Метою роботи є побудова відтворюваного середовища для навчання моделей машинного навчання. Проект реалізує систему класифікації текстових повідомлень з датасету *20 Newsgroups* за допомогою MLOps інструментів.

В проекті реалізовано:
- Версіонування коду за допомогою Git  
- Версіонування даних та моделей за допомогою DVC (Data Version Control)  
- Відстеження експериментів та метрик у MLflow  
- Автоматизацію обробки тексту через scikit-learn Pipeline (TfidfVectorizer + Classifier)

## 3. Швидкий старт
Встановлення залежностей

```bash
# Створення віртуального середовища
python -m venv venv
source venv/Scripts/activate  # Для Windows

# Встановлення пакетів
pip install -r requirements.txt
```bash

Отримання даних через DVC
Проект використовує локальне сховище для даних.
```bash
# Ініціалізація та отримання даних
dvc pull
```bash

Запуск тренування та MLflow

Для запуску серії експериментів з різними моделями (Naive Bayes, Logistic Regression, Linear SVC):

```bash
# Завантаження датасету (якщо вперше)
python src/data/download_data.py

# Запуск тренування
python src/train.py

# Перегляд результатів в UI
mlflow ui
```bash

## 4. Результати експериментів

Під час виконання було проведено порівняння трьох типів моделей для класифікації тексту.

| Модель (Run Name) | Параметри | Accuracy | Нотатки              |
| ----------------- | --------- | -------- | -------------------- |
| NB_Alpha_0.1      | alpha=0.1 | ~0.89    | Найкраща швидкість   |
| LogReg_C1.0       | C=1.0     | ~0.91    | Стабільний результат |
| LinearSVC_C0.1    | C=0.1     | ~0.93    | Найкраща точність    |

Висновок: Найкращий результат показала модель Linear SVC. Використання TfidfVectorizer з обмеженням у 5000 ознак дозволило ефективно працювати з текстовими даними без перенавчання.
